# A Head-On Comparison of EQ-VT- and Crosswalk-Based EQ-5D-5L Value Sets

## Abstract

### Background

No systematic country-level comparison has been undertaken between crosswalk- and EQ-VT-derived EQ-5D-5L value sets. Crosswalk values can differ from EQ-VT-based EQ-5D-5L value sets owing to valuation protocols, changes in societal preferences over time, and a change in the label of the highest level on mobility in moving from EQ-5D-3L to EQ-5D-5L. This study aimed to compare the five-level (5L) crosswalk and EQ-VT value sets to explore differences between them at the country level.

### Methods

From the countries with both time trade-off (TTO)- or discrete choice experiment (DCE) + TTO-based EQ-5D-3L value sets and EQ-VT-based EQ-5D-5L value sets, 19 pairs of EQ-5D-3L/EQ-5D-5L sets were found. For each of these EQ-5D-3L value sets, 5L crosswalk sets were developed and compared with the corresponding national EQ-5D-5L valuation set using correlation analysis, ranges, values of specific states, Bland–Altman plots, and scatter plots. Three of the countries have EQ-5D-3L and EQ-5D-5L valuation data for the same set of respondents. These three cases were analyzed separately, as they provide a “true” test of the differences between the two value sets.

### Results

Spearman correlation between the crosswalk and valuation sets ranged from 0.831 to 0.989, being below 0.9 in 11 pairs of value sets. The difference in the percentage of negative values ranged from +22.5 to −18.8%, and the difference in the ranges within each pair of value sets ranged from +42.7 to −18.4%. The average mean absolute difference of values (crosswalk versus EQ-VT) was 0.149. This was below 0.1 in only 5 of the 19 EQ-VT/crosswalk set pairs. For the states comprising one level 5 and four level 1s, no country preserved its ranking of importance of the five dimensions in moving from crosswalk to EQ-VT values. Most of the Bland–Altman plots and scatterplots revealed a pattern that placed states with the highest level on mobility as a separate band from other states.

### Discussion

All of the criteria showed poor agreement between the crosswalk- and EQ-VT-based value sets. The differences in labels for the most extreme response option for the mobility dimension leads to substantial differences in values between these value sets.

### Conclusions

Crosswalk and EQ-VT value sets should not be used interchangeably, except under circumstances where it is not possible or feasible to conduct a direct EQ-5D-5L valuation study.

## Background

The EQ-5D (developed by the EuroQol Research Group) is the most commonly used generic preference-based measure of health-related quality of life internationally. EQ-5D is used in economic evaluation, population health studies, burden of illness research, and health inequality studies. The EQ-5D classification system comprises five dimensions in this order: mobility, self-care, usual activities, pain/discomfort, and anxiety/depression. In the original EQ-5D instrument (EQ-5D-3L), each dimension had three levels: no problems, moderate problems, and extreme problems/unable to. For the first dimension, mobility, the highest level of problems was labeled “confined to bed.” In 2009, the EuroQol Research Group released a five-level instrument (EQ-5D-5L) that included two additional levels for each dimension: slight (between no- and moderate problems) and severe (between moderate- and extreme problems) \[1\]. For the mobility dimension, the highest level was labeled “unable to walk about.” The five-level instrument proved to be more sensitive than the three-level instrument, particularly for milder illnesses \[2\]. There was no standard approach for conducting EQ-5D-3L valuation studies. Such studies were conducted using various adaptations of time trade-off (TTO), visual analog scale \[3\] and eventually discrete choice experiment (DCE) approaches \[4\]. With the introduction of the EQ-5D-5L, the EuroQol Group also introduced a standardized valuation protocol known as EuroQol Valuation Technology (EQ-VT) \[5\] which includes DCE and composite time-trade-off (cTTO) valuation tasks. This protocol has been described elsewhere \[6, 7\].

To date, more than 35 EQ-5D-5L value sets have been developed using the EQ-VT protocol, with several more valuation studies underway. Many of the countries with EQ-VT-derived EQ-5D-5L value sets also have EQ-5D-3L value sets, as EQ-5D was being used in those countries before the introduction of the EQ-5D-5L. In those countries, prior to conducting their own EQ-5D-5L valuation studies, the introduction of the EQ-5D-5L provided a challenge: a new instrument with better measurement properties was available, but there were no value sets, which made it impossible to score EQ-5D-5L health states. An interim solution for that was provided by Van Hout et al. \[8\], and later by Van Hout and Shaw \[9\]. Van Hout et al. \[8\] developed the so-called crosswalk algorithm, or a “response mapping,” which allows calculation of the probability of a respondent reporting a certain EQ-5D-5L health state given their EQ-5D-3L response (or vice versa). This allows values to be assigned to EQ-5D-5L health states where only an EQ-5D-3L value set is available. The assumption here is that the underlying preferences associated with the EQ-5D-3L and the crosswalk EQ-5D-5L value set are the same. If this holds true, then ceteris paribus, a crosswalk value set can be used in place of an EQ-VT value set.

One disadvantage of the crosswalk algorithm is that the subsequent EQ-5D-5L value set is not derived directly and that the validity of the resulting crosswalk EQ-5D-5L value set relies on several assumptions. It is assumed that the underlying EQ-5D-3L value set was developed using a sound methodological strategy. Another assumption is that the preferences collected for the underlying EQ-5D-3L value set are still valid (e.g., the EQ-5D-3L value set may be very old, which questions whether the values would still be applicable to the current population). Further, the population on which the crosswalk algorithm was developed (which comprises European patients) would need to be representative for the target population (which may not be European). In addition to these assumptions, the labels for mobility differ between the EQ-5D-3L and EQ-5D-5L, with the most extreme level being “confined to bed” in the EQ-5D-3L and “unable to walk about” in the EQ-5D-5L. It is possible that a response mapping may accurately describe how patients report their own health in the mobility dimension for the EQ-5D-3L and EQ-5D-5L, but that respondents may value the labels “confined to bed” and “unable to walk about” in different ways. When using a crosswalk algorithm, the subsequent value for “unable to walk about” in the EQ-5D-5L is then based on “confined to bed” in the EQ-5D-3L, which may lead to biased health state values.

The problem associated with this change in the label was recently observed in the EQ-5D-5L valuation study for Trinidad and Tobago \[10\], where some remarkable differences were observed between the EQ-VT-derived EQ-5D-5L value set and the preexisting crosswalk value set. The Bland–Altman plot in Fig. <a href="#Fig1" data-ref-type="fig">1</a> is adapted from a similar display in the Trinidad and Tobago study \[10\] showing that in the case of Trinidad and Tobago, the values assigned to health states with mobility level 5 formed a mutually exclusive group in terms of value from the health states that do not have level 5 problems on mobility. The scatterplot in Fig. <a href="#Fig2" data-ref-type="fig">2</a> shows the same pattern.

In terms of the three assumptions concerning the validity of a crosswalk set, there were major differences between the methods used to generate the EQ-5D-3L value set for Trinidad and Tobago (which was based on DCE, anchored using TTO data \[11\]) and the EQ-5D-5L value set (which used the EQ-VT). In addition, the EQ-5D-3L value set preference data were collected 7 years before the EQ-5D-5L valuation study. Finally, the European population on which the crosswalk algorithm is based may not be representative for Trinidad and Tobago \[12\]. The difference between the two value sets is striking, especially given the fact that the differences are so large specifically for one level on one dimension.

This leads to the following research questions:

1.  For countries with both EQ-5D-3L and EQ-5D-5L value sets, to what extent do crosswalk-based value sets (based on EQ-5D-3L) differ from EQ-VT value sets for the EQ-5D-5L from the same country?

2.  To what extent may differences in the labels for the most extreme response options for mobility explain differences between value sets based on the crosswalk algorithm or EQ-VT?

Differences between crosswalk value sets and EQ-VT-derived EQ-5D-5L value sets have been investigated previously. In one study \[13\], the effect of using the crosswalk versus the EQ-VT value set was investigated by applying the two value sets from three countries to EQ-5D-5L states from randomized controlled trial datasets in depression and diabetes, and then calculating the resulting quality-adjusted life years (QALYs) and incremental cost-effectiveness ratios (ICERs) and comparing them. Mean utilities were lower based on the EQ-VT value set in one country (the Netherlands) but higher in the other two countries (England and Spain). Despite these differences, the distribution of bootstrapped cost–effect pairs on the cost-effectiveness plane was similar for the crosswalk and EQ-VT value sets using health states from both datasets in all three countries. The authors concluded that, for these two datasets, the crosswalk and EQ-VT value sets could be used interchangeably in all three countries. A subsequent study \[14\] investigated applying crosswalk- and EQ-VT-derived value sets for the Netherlands, the USA, and Japan to trial-based, simulated data in four conditions (depression, low back pain, osteoarthritis, and cancer) with various severity levels and effect sizes. This study found that cost–utility differences between the crosswalk- and EQ-VT-derived value sets were large enough to influence reimbursement decisions. This was especially so for cost–utility pairs that were in the first quadrant of the cost-effectiveness plane (where such analyses are most useful for decision-making). This study also found that differences in reimbursement decisions (between crosswalk- and EQ-VT-derived value sets) were more likely for countries that were not included in the development of the crosswalk. These two studies investigated the effect of the value set (crosswalk- versus EQ-VT-derived) on QALY estimates, ICERs, and reimbursement decisions. No study has directly compared EQ-VT- and crosswalk-derived value sets. In our study, we conducted direct comparisons of the crosswalk- and EQ-VT-derived value sets for all countries that had TTO- or DCE-derived EQ-5D-3L value sets and EQ-VT-derived EQ-5D-5L value sets.

## Aims of the Study

This study aimed to directly compare EQ-VT and crosswalk value sets to explore differences between them at the country level. This would provide insight into differences due to:

- Scale: Various methodological differences between EQ-5D-3L and EQ-5D-5L studies may cause differences in willingness to trade life years, which affects the scale of the value set. These methodological differences include differences in valuation method (TTO versus cTTO and DCE) and better implementation of the valuation methods using quality control processes \[15\].

- Actual differences in preferences that may have changed over time: For example, greater awareness of mental health may raise the importance of the anxiety/depression dimension. The experience of the covid 19 lockdown might have increased the salience of the usual activities dimension in some countries.

- The instrument: Changing the highest level of problems with mobility from “confined to bed” to “extreme problems with walking about” may evoke different choices in a valuation situation, leading to much lower values for all EQ-5D-3L states with level 3 on mobility (relative to the rest of the 3L value set) than 5L states with level 5 on mobility (relative to the rest of the value set).

## Methods

A secondary data analysis of published and unpublished value sets was conducted to explore the research questions. For EQ-5D-3L, 25 value sets were identified that were either TTO- or DCE + TTO-based. For EQ-5D-5L, 32 value sets were identified that were EQ-VT-based. This provided a set of 18 countries that have both TTO- or DCE + TTO-based 3L value sets and EQ-VT-based 5L value sets \[10, 11, 16–49\]. One country (the USA) had an additional 3L and EQ-VT pair from a parallel valuation study; thus, 19 EQ-5D-3L sets were used from 18 countries. For each of the 19 EQ-5D-3L value sets, crosswalk sets were developed using the Van Hout et al. crosswalk algorithm \[8\]. Each crosswalk set was then compared with the corresponding national EQ-5D-5L valuation set using several criteria.

The key charactersitics of the value sets were investigated using:

- Range of values.

- Mean values of the value sets.

- Value of state 55555 (the highest level of problems on all five dimensions). This was included in addition to the range because some of the value sets did not have a maximum of 1.000.

- Percentage of states worse than dead (negative index values).

Differences in the relative values of the five dimensions were investigated using the change in ranks of the values of the five states with four dimensions at level 1 (no problem) and one dimension at level 5, since each of these states isolates the impact of one dimension. Special attention was paid to state 51111 since the description of the highest level on mobility changed in transitioning from the three-level to the five-level instrument.

To investigate differences in more severe states, mean values of all states with level sum scores (LSS) of over 15 (the sum of the levels on the five dimensions) were compared.

To test for statistical difference in the mean values, *t* tests for the mean values for both the complete value sets and the LSS \> 15 subsets were calculated.

Spearman and Pearson correlation coefficients were calculated for each pair of value sets. To assess the level of agreement, we also computed Lin’s concordance correlation coefficients, as well as the mean absolute difference (MAD) for the two value sets, on the basis of the full set of 3125 possible health states. The time span between the publication of the EQ-5D-3L valuation study and the EQ-VT study was used as a proxy for the number of years that elapsed between the valuation surveys that produced the crosswalk and the EQ-VT value sets. This was included to investigate whether there was any association between correlation between crosswalk- and EQ-VT-derived value sets and the interval between the two valuation studies. This was done using correlation analysis on the intervals and the correlation coefficients. Over time, societal preferences can change, resulting in changes in the relative importance of the five dimensions to a population. A longer time interval between the two valuation studies would allow for a greater opportunity for such changes to take place.

Scatterplots and Bland–Altman plots were generated to assess whether the value sets measured the same construct. Special attention was paid to health states that had a level 5 on mobility to assess whether there were any differences for these. These analyses provided information on the agreement between value sets based on the crosswalk algorithm and those based the EQ-VT, given the assumptions underlying the crosswalk algorithm. However, they would not allow a direct assessment of the effect of valuing “confined to bed” and “unable to walk about,” as the effect may be masked by methodological differences, differences in the population over time and the sample, or the possibility that the population on which the crosswalk algorithm is based may, in theory, not be representative for some of the included countries.

To assess this problem directly, we identified 3 of the 18 countries that collected EQ-VT data for both the EQ-5D-5L as well as the EQ-5D-3L from the same respondents, although each respondent completed a smaller subset of cTTO tasks for the EQ-5D-3L compared with the EQ-5D-5L. In each of these parallel valuation countries (Hungary, Romania, and the USA), both 3L and 5L value sets were published on the basis of this data. Each of these publications report several models for both the EQ-5D-3L and EQ-5D-5L estimates, and we selected the same model for the EQ-5D-3L and EQ-5D-5L in each country. This allowed a direct comparison of crosswalk value sets based on newly collected EQ-VT data for the EQ-5D-3L with EQ-VT-based EQ-5D-5L value sets from the same respondents, using similar methods. This may be the fairest comparison between the EQ-VT- and crosswalk-based value sets, as it eliminates (most of) the methodological differences between the source value sets for the crosswalk and the EQ-VT, and it eliminates differences in the population between the value sets; finally, since the countries for which the data were available are the USA and two European countries, it is more likely that the response data on which the crosswalk was based would have been more representative for these three countries. The same analyses were conducted on these three crosswalk/EQ-VT combinations as were for the 16 other combinations of crosswalk and EQ-VT value sets in which the data were not collected simultaneously. The analysis therefore included 18 countries but 19 EQ-VT/crosswalk pairs because the USA is included in both groups: for example, the USA has produced independent EQ-5D-3L and EQ-5D-5L value sets \[40, 44\] and a separate parallel valuation study \[29\].

For the three parallel valuation countries, we also developed Bland–Altman plots for reverse-crosswalk three-level sets. For example, the five-level value sets from the three parallel valuation countries were used to create three-level crosswalk sets. Bland–Altman plots were then created to compare the three-level crosswalk sets with the three-level valuation sets for the three countries, with special emphasis on the states with mobility at level 3 (MO3), to test whether the MO3 states were a clearly distinguishable group.

Finally, the value sets were applied to a mixed-population dataset called the multi-instrument comparison (MIC) dataset \[50\]. This dataset contains EQ-5D-5L responses for patients from five different countries, suffering from one of the following conditions: arthritis, asthma, cancer, chronic obstructive pulmonary disease (COPD), depression, diabetes, chronic heart disease, stroke, or hearing problems, as well as healthy patients. A total of 7933 respondents was included in the dataset. The crosswalk and EQ-VT value sets were applied to the data, and one-sample *t* tests were used to test whether the mean utilities differed between the two value sets for each country. Subanalyses were performed to see whether the means differed in respondents with severe health problems (LSS \> 15) and in respondents reporting level 5 on mobility.

## Results

Crosswalk EQ-5D-5L value sets were generated from DCE- and/or TTO-based EQ-5D-3L value sets for 16 countries \[11, 17–20, 24, 25, 28, 30, 31, 33, 43, 44, 46–48\]. These were compared with the corresponding-country EQ-VT-derived EQ-5D-5L value sets \[10, 16, 21–23, 26, 27, 32, 34–36, 38, 40, 41, 45, 49\]. For three countries, EQ-5D-3L and EQ-5D-5L valuation data came from the same respondents \[29, 37, 39, 42\]. Applying the values to the MIC data (*n* = 7933 respondents) showed that, for all 19 pairs of value sets, the population mean differed significantly between crosswalk and EQ-VT. In 14 out of 19 pairs, the mean utility was higher in the EQ-VT value set compared with the crosswalk. In the other five pairs, a lower mean was reported in the EQ-VT compared with the crosswalk. The largest MAD was 0.141 for Denmark, while the smallest MAD was 0.007 for the USA (comparison between parallel collected datasets). When looking at more severe states, defined as states with LSS higher than 15 (*n* = 305), the means differed significantly for each country as well. Higher means for the EQ-VT were reported for 13 pairs, versus 6 pairs reporting higher means for the crosswalk. The largest MAD was found for Italy, at 0.434, while the smallest MAD was found for Poland, at 0.009. Finally, when looking at respondents reporting being “unable to walk about” (*n* = 28), we found that, out of 19 pairs, 13 reported a lower mean for the crosswalk versus the EQ-VT, while 4 reported a lower mean for the EQ-VT. For two pairs, there was no significant difference. The largest MAD was found for South Korea at 0.355, while the lowest MAD was found for Japan at 0.035.

## Discussion

The correlation coefficients of less than 0.9 in more than half of the value set pairs, the differences observed in the ranges, mean value (and the associated *p*-values) changes in the ranking of the five dimensions within value set pairs, the Bland–Altman plots, and scatterplots all point to poor agreement between several crosswalk and EQ-VT value sets. These differences were also observed in the value sets of the three parallel valuation studies. This suggests that crosswalk- and EQ-VT-derived value sets should not be used interchangeably. Furthermore, the “confined to bed” label seems to be valued differently from “unable to walk,” which is reflected in the difference between crosswalk and EQ-VT value sets, which the crosswalk insufficiently considers. These differences persisted when comparing EQ-VT EQ-5D-5L value sets with crosswalk value sets derived from EQ-5D-3L responses from the same sample, suggesting that, ceteris paribus, the differences in labels for the most extreme response option for the mobility dimension leads to substantial differences in values between these value sets. This has implications for transferability between 3L and 5L, the use of crosswalk sets, and the comparability of Health Technology Assessment (HTA) results based on the two instruments. Some evidence points to the possibility that, over time, the underlying societal preferences among the five dimensions can change, so even further caution should be used when applying crosswalk value sets based on very old EQ-5D-3L valuation studies.

Consideration could be given to restricting the use of crosswalk value sets to situations in which the population size is so small that an EQ-VT valuation study is not possible or is nonfeasible. For example, a population of less than 200,000 can require nearly 1% of the adults to take part in a valuation study. To facilitate such small-population situations, further studies could be undertaken to test whether there is any improvement in comparability by changing the highest level on mobility in EQ-5D-3L to the same label as used for the EQ-5D-5L.

This is the first study to directly test the similarity of EQ-5D-5L crosswalk- and EQ-VT-derived value sets and to quantify the differences at country level. The main limitation of this study is that, while evidence was found for important differences in value sets that may be due to time, the labeling of the highest level on mobility, or the valuation method, the small number of pairs does not permit further investigation to quantify the relative importance of these three drivers of differences between value sets. As further EQ-VT-based EQ-5D-5L value sets are produced, such investigations can be conducted and extended to include the effect of modeling approaches and diagnostic performance of models versus actual data.

## Conclusions

This study has found differences between crosswalk- and EQ-VT-based value sets for EQ-5D-5L. The recommendation is that, where possible, EQ-5D-5L value sets should be based on direct valuation. Crosswalk values can still be used in smaller populations where large valuation surveys cannot be conducted. For situations in which an EQ-5D-5L value set is required for larger populations but resource or other constraints do not allow interviewer-led valuation processes, a DCE with a duration attribute, taking into account time preferences, may be used \[51\]. A recent study has shown that such a protocol can produce similar results to an EQ-VT study, while it can be conducted via an online survey, greatly reducing the resources required \[52\].
