## Result

needs a family gap. The main part-level design and data axes also fit without
a new controlled value or key.

Design values have this order: `component_approach / temporal_structure /
comparison_structure / allocation_structure`. A bracket gives an applicable
mixed-method or synthesis design. Data values have this order:
`data_origin / data_level`. `P1`, `P2`, and `P3` identify separable parts.
Each observed byte count and SHA-256 below matches its manifest value.
