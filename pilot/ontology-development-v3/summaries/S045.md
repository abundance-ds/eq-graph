## Aim and working definition

The paper develops a taxonomy for deciding whether health-related quality-of-life (HRQoL) value sets are obsolete, how to detect obsolescence, and what response is suitable. It considers EQ-5D examples but states that the issues apply to other preference-weighted HRQoL instruments (Abstract; Introduction). Value sets support QALY-based cost-utility analysis, HTA/resource allocation, and non-QALY summaries of routine PROM data. The authors note no external gold standard or agreed definition of value-set validity.

They tentatively define HRQoL value-set validity as the extent to which values for a descriptive system (a) sufficiently represent average preferences of the population of interest and (b) have empirical/theoretical properties acceptable in the decision context. Context validity includes anchoring at 0 and 1, interval-scale properties, choice-based methods, sample frame, elicitation, quality assurance, analysis, modelling, and final-model selection (Introduction; “Challenges in Defining Obsolescence…”).

## Four types of obsolescence

1. **Type 1—misaligned with normative views.** A value set is obsolete when HTA decision makers adopt a different normative basis, such as patient values or children’s own views, or stop recommending the instrument/QALY paradigm for the relevant purpose. The response is normally a new value set aligned with guidance; no additional evidence is needed if the normative requirement itself is clear.
2. **Type 2—methods outdated and/or unreliable.** Changes may concern stated-preference task, administration mode, quality control, data analysis, and modelling. If original data can be re-analyzed, update the analysis. If not, a small method-comparison study can estimate magnitude; retain the old set if differences are modest or conduct a new study if they matter.
3. **Type 3—population change.** Type 3a is changed population composition, such as ageing or immigration, even if subgroup preferences are stable. Resampling/reweighting original data can test or address this if adequate subgroup data exist. Type 3b is preference change from new expectations, awareness, COVID-19, euthanasia, end-of-life care, or abortion. Qualitative or small quantitative monitoring can identify change; stable new norms may justify a new contemporary valuation study.
4. **Type 4—instrument change.** Wording, translation, severity, or descriptive-system changes mean the value set no longer exactly matches the instrument. A small study comparing original and updated wording can test impact; new valuation with updated wording may then be needed (Sections “A Taxonomy…” and “What Evidence…”).

## Evidence and solutions

The source’s Table 1 maps type to evidence and action. Type 1 needs no empirical test if driven by HTA guidance. Type 2 needs evidence that changing methods changes the set. Type 3a needs resampling to test mean-preference change; type 3b needs qualitative or small quantitative evidence of changing attitudes. Type 4 needs a small valuation study using original and updated wording. Solutions range from sensitivity analysis, re-analysis, quality-control exclusions, and reweighting to new value-set data collection (Section “What Evidence…”).

## Decision and transition implications

Obsolescence is a judgment, not a simple function of time. New value sets cost money and may change incremental QALYs, ICERs, comparability with historical analyses, and threshold interpretation. Stakeholder engagement is needed for acceptance and to avoid value-set selection/gaming. The authors question whether older sets should be actively decommissioned and whether historical decisions need reappraisal; positive recommendations are unlikely to be reversed, but sponsors may seek reconsideration when new values improve cost-effectiveness (Section “The Cost of Transitions…”).

## Limitations and open questions

The paper does not define a universal threshold for “too big to ignore”, identify a single responsible party, or provide a universal update schedule. Solutions must be tailored to local conditions, data access, HTA requirements, cost, and acceptability. The authors call for research on reweighting, monitoring, expected value of perfect information, and decision-maker engagement (Conclusions).
