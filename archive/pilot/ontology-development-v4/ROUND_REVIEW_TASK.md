# Typed ontology round review

Compare two independent applications of one ontology to the same paper batch.
Do not edit either application.

Read the current `ONTOLOGY.md`, protocol, round manifest, both application
files, and the round-1 applications and gaps. Check article passages only when
a disagreement can change a key, value, or mapping.

For each disagreement or proposed addition, return `MERGE`, `ACCEPT`, `REJECT`,
or `KEEP_OPEN`. Test whether it is a synonym, a composite value, a recurring
scientific distinction, reliably extractable, and useful across papers.

Report:

- agreement on primary family and controlled axes;
- material mapping disagreements;
- accepted, rejected, merged, and open proposals;
- effects on earlier papers;
- a revised cumulative application table;
- whether the ontology is stable enough for a larger batch;
- exact inputs and source checks.

Do not read Neo4j guidance, old proposals, graph records, or prior extraction
records.
