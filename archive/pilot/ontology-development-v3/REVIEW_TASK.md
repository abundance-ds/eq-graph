# Proposal review and synthesis

Review the three ontology proposals against the complete evidence set and all 100 questions.

## Review criteria

- EuroQol meaning: Do the terms match how researchers describe this work?
- Query value: Are high-value facts exact and searchable?
- Coverage: Can the model represent the important facts in all study families?
- Question support: Can the complete system answer each competency question?
- Findings: Can it represent useful findings without participant-level data or exhaustive result tables?
- Granularity: Are instruments, methods, analyses, populations, and products detailed where users need detail?
- Clarity: Does each concept have a plain meaning and a good example?
- Separation: Does it distinguish publications, studies, projects, extracted facts, and derived analytics?
- Restraint: Does it avoid unsupported classes, duplicate concepts, and unnecessary nesting?
- Evidence and provenance: Can each proposed concept, relation, controlled value, and example be traced to a supplied summary or question?
- Term fidelity: Does it distinguish source labels, canonical labels, aliases, and derived classifications?
- Answerability: Does each question identify the concepts and relations it needs, and whether its answer needs external data?
- Consensus restraint: Is each accepted concept supported by evidence, and not only by agreement between proposals?
- Implementation fit: Can a target data store, relational or graph, implement the model without loss of meaning?

## Final output

Write:

- a concise comparison of the three proposals;
- accepted and rejected design choices with reasons;
- a final human-readable ontology proposal;
- examples that show exact EuroQol values from supplied summaries, with provenance and clear labels for derived values;
- a coverage map for all 100 questions;
- open decisions that require human judgment.
