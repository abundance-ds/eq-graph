We have developed the R package hyreg2, which enables the estimation of EQ-5D-5L value sets based on the hybrid model. To account for preference heterogeneity, latent class estimation is implemented using the EM-algorithm, as available in the flexmix package. Our package adopts the data preparation and E-step from flexmix and introduces a new M-step incorporating the likelihood of the hybrid model. In addition, hyreg2 provides functions for summarizing and visualizing results (summary, plot). The package further allows for modeling heteroscedasticity and estimating partial coefficients, thereby extending the methodological possibilities beyond those available in hyreg (Stata) or xreg (R). Importantly, hyreg2 follows the typical input conventions of R. The package was submitted to CRAN on September 30, 2025. Until it is published there, it can be installed using use devtools::install_github("Selk19/hyreg2").Its functionalities were evaluated in a simulation and case study. For this purpose, two simulated datasets as well as the publicly available EQ-5D dataset (https://github.com/intelligentaccident/EQ5D_data) were used. The results demonstrated that controlling for groups (i.e. participants) is essential; without it, the model tends to group all TTO data to one class and all DCE data to the other. While group control is already available for the E-step, this functionality is unfortunately not yet implemented in the M-step. In particular, the analyses with the EQ-5D dataset highlight that hyreg2 is highly able to account for preference heterogeneity in the TTO data. Best results are generated using a two-step approach, which is also implemented in the package: First latent classes are uncovered only on the TTO data and afterwards on these classes the hybrid model is used on the TTO and DCE data to estimate the value sets.
