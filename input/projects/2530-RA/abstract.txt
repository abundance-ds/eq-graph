BackgroundIn EQ valuation, discrete choice experiments are becoming increasingly important, and the design of these tasks has direct consequences for both respondent burden and statistical efficiency. One important design feature is attribute level overlap, where one or more dimensions are held constant between alternatives within a choice task. Although overlap can reduce task complexity, it also reduces the statistical information generated by each choice. Determining the appropriate amount of overlap is therefore an important design question. This is especially the case for EQ-HWB-9, where the 9-dimensional structure makes unconstrained choice tasks substantially more demanding, while it remains unclear whether this is desirable. Project aimThe project aims to determine the optimal amount of attribute level overlap for the EQ-HWB-9 instrument. As no EQ-HWB-9 valuation data are currently available for this purpose, primary data will be collected. Different overlap conditions, defined by the number of dimensions held constant between alternatives within a choice task, will then be compared to identify the level that best balances task complexity and statistical efficiency.MethodsAn online DCE study will be conducted in a UK general population sample using the EQ-HWB-9 instrument. Respondents will be randomly allocated to one of eight experimental arms, each representing a different degree of attribute level overlap, ranging from 0 to 7 overlapping dimensions within a choice task. The overlap conditions will be compared using indicators of response efficiency, statistical efficiency, respondent behaviour, and data quality. The main analysis will use mixed logit models, with alternative estimation approaches examined where necessary to address the convergence and identification difficulties associated with high-dimensional EQ-HWB-9 data.
