This project was envisaged as developing a tool for real-time decision making by clinicians, specifically mental healthcare professionals working in an NHS community out-patient clinic. A data collection procedure was agreed in which patients completed an EQ-5D questionnaire whilst in the waiting room. This was then entered by the clinician into a bespoke analysis program with a menu of standardised reports, for example demonstrating changes in dimension response levels over time, alterations in EQ VAS and age/sex comparisons against population norms. The analysis system was expected to "learn" over time, so that new patients could be compared against cohort of patients who had previously attended the clinic. Software was designed, commissioned and delivered to the NHS provider who had jointly agreed the project. Practical issues immediately became apparent, notably the requirement to operate all software behind the NHS firewall. Despite initial progress in dealing with such implementation problems, the software was deemed a technical success. The project effectively collapsed when the NHS co-PI unexpectedly relocated. Efforts to resuscitate the project were ultimately unsuccessful. The software package (EQ5Drt, where the subscript rt indicates Real Time) was subsequently made available to colleagues in Hong Kong for use as a real-time application with MSK patients/
