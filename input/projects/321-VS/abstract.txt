The importance of preference-based health-state utility values rises as countries shift towards using cost-utility analysis to inform healthcare priority setting. However, very few Asian value sets for child preference-based instruments are available. Thus, this study aimed to develop EQ-5D-Y-3L value sets for Malaysia, Singapore, Taiwan, and Vietnam. A multi-country EQ-5D-Y-3L valuation study was conducted using the international EQ-5D-Y-3L valuation protocol with a larger composite time trade-off (cTTO) design. Two general population samples from Malaysia, Singapore, Taiwan, and Vietnam were surveyed to elicit their preferences for EQ-5D-Y-3L health states using either the cTTO method or a discrete choice experiment. A hybrid latent class model was used to estimate the EQ-5D-Y-3L value set for each participating country. Approximately 200 (range: 200-207) and 1000 (range: 1006-1047) respondents from each participating country completed the cTTO and DCE surveys, respectively. A latent class model with six classes fit the DCE data collected from Malaysia and Taiwan best; a model with four and five classes fit Singapore’s and Vietnam’s DCE data best, respectively. The model predicted value for the worst EQ-5D-Y-3L state (i.e. 33333) was -0.242 in Malaysia; -0.397 in Singapore; -0.582 in Taiwan; and -0.198 in Vietnam. The second highest value in all countries was for health state 12111, ranging from 0.928 in Taiwan to 0.966 in Malaysia. EQ-5D-Y-3L value sets for Malaysia, Singapore, Taiwan, and Vietnam were generated concurrently using a robust protocol for healthcare decision making involving child and adolescent populations. The hybrid latent class modelling approach may be considered in future EQ-5D-Y-3L value set studies.
