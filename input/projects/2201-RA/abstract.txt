Background: Economic evaluation of health technologies and interventions requires the generation of health benefits across the life-course, meaning the assessment of health for patients at different ages from childhood through adulthood. However, different measures are recommended depending on age (EQ-TIPS, EQ-5D-Y, EQ-5D-xL), and the health state and accompanying utility value will vary due to the valuation study conducted for each specific measure and not due to a difference in underlying health. No existing project has explored, using both data and theory, how to generate consistent utilities and (quality-adjusted life years) QALYs across the life-course from childhood to adulthood. Aim: This project aim is to explore and critically assess potential methods to generate consistent utilities and QALYs across the life-course where the use of measure differs depending on the age of the patient, through the use of a case study utilising forthcoming UK value sets for EQ-5D-5L and EQ-5D-Y-3L. Methods: This project will explore four different approaches using a case study of forthcoming UK value sets for EQ-5D-5L and EQ-5D-Y-3L: 1) Estimating a conversion of the EQ-5D-5L value set using extrapolation of preferences by age; 2) mapping between EQ-5D-Y-3L and EQ-5D-5L utilities using existing value sets; 3) mapping between EQ-5D-Y and EQ-5D-5L adolescent responses to each measure; 4) estimating a conversion of the EQ-5D-Y-3L value set to have the same range as the EQ-5D-5L value set. The project will critically assess each approach including theoretical framework, pros and cons, feasibility and appropriateness of indicative results using the case study, and comparability of results.
