The launch of the Bolt-on Toolbox necessitates development of valuation methods for bolt-ons. Subsequently, to equip this toolbox with country-specific value sets will be a big endeavour in view of the multiplicity of bolt-ons and countries. The core dimension value sets differ between countries, so offering a single bolt-on value set for multiple countries is guaranteed to result in gaming in at least some of the countries. The present proposal offers to seek a possible solution to the problem by studying the strength of association between preferences for core dimensions and for a selected bolt-on (cognition). Specifically, we plan to design and test a novel approach that will estimate the link between these two preferences. If the association between preferences is strong, then preferences for bolt-ons can be to some extent inferred from the core value sets which could perhaps reduce sample sizes in the bolt-on valuation studies of help with developing methods to transfer preference information between countries. We will recruit 300 respondents from prolific to online interviews. In these interviews, we will elicit preferences for health states defined using only core dimensions or also a bolt-on item using TTO in two arms: A) first core and then bolt-on health states; B) only bolt-on health states. In the modelling, we will use the CALE model specification, to reduce the number of parameters. For core dimensions health states, we will estimate the dimension importance and the relative importance of levels. For the bolt-on health states, we will estimate how the importance of bolt-on item is associated with the importance of core dimensions relative to the bolt-on-specific preferences.
