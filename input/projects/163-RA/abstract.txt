Aim: We aimed to create a model estimation tool that will enable EuroQol researchers to efficiently analyze their discrete choice experiment (DCE) with duration data with mixed logit (MIXL) choicemodels that accommodate non-linear time preferences. Methods: The MIXL choice models are optimized using Maximum Likelihood (ML) estimation techniques, with the integration over the respondents’ preferences performed using Simulated ML instead of Laplace approximations. After estimation, the software provides the end-user with parameter estimates, standard errors, 95% confidence intervals, and the QALY tariff. Software implementation: The software is bundled into an easily distributed R package. The underlying computational engine of the software is programmed in an efficient, low-level language (C++), and an R interface enables users to analyze their data directly in R - similar to any other R function.
