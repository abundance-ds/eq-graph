Objective: To develop an EQ-5D-5L value set for the Brazilian population. Methods: We will develop a value set using the composite time-trade-off (cTTO) and discrete choice experiment (DCE) approaches. One thousand adults from general population will be included in this valuation study. The study will be conducted in six urban centers: two in Southeast region (Ribeirão Preto and São Paulo - São Paulo) and one in each other regions: South (Uruguaiana - Rio Grande do Sul), North (Belém - Pará), Northeast (Fortaleza - Ceará), and Central-west (Distrito Federal - Brasília). Different model specifications will be tested using only cTTO data, only DCE data, and hybrid approaches combining both. Sensitivity analyses will be performed to assess the robustness of the model estimates.Discussion: Economic evaluations have been increasingly conducted in Brazil to support healthcare decision-making processes. The quality of these studies is considered satisfactory. However, improvements are needed especially in the methods used to estimate effect measures such as health-related quality of life considering the Brazilian scenario. Evidence shows that the EQ-5D-5L demonstrates superior measurement properties compared to the EQ-5D-3L. However, a value set for the EQ-5D-5L has not been developed for the Brazilian population yet. The development of this value set will facilitate the dissemination and use of this instrument in clinical and research settings across Brazil.
