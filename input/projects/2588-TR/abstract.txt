The EuroQol Quality Control (QC) tool was initially developed by Juan M. Ramos-Goñi while working for the EuroQol Office. Its initial development started in 2013, and it has been in use in a lot of valuation studies up to nowadays. The current version keeps being Excel-based while it has turned out to be an EQ-VT2 Data Tool which downloads and parses data directly from EQ-VT2 servers. While during more than 10 years it has been a very powerful tool, it has several limitations including user’s control, cross-platform compatibility, especially with Mac users, and may be hindered by antivirus software and system configurations. This proposal aims to address these challenges by transitioning the Data Tool into a web-app solution implemented in R/Shiny. By doing so, we can achieve a more user-friendly experience, ensure compatibility across various devices, and implement enhanced security features like Two-Factor Authentication. The result will be a more robust, scalable, secure and accessible web-app platform keeping the same flexibility.
