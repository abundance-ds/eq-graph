Background: EQ-5D is a widely used tool for assessing health related quality of life. Health state profiles can be analysed using several methods, though commonly they are converted into a single utility index using country-specific value sets. Calculating EQ-5D utility values manually can be challenging, time-consuming and prone to errors. The Egyptian EQ-5D-5L was developed and published since 2021 and no EQ-5D utility index score calculator was developed.Aim: To develop a user-friendly EQ-5D Egyptian utility index score calculator that allows healthcare professionals and researchers to easily calculate EQ-5D utility values for different health states. This calculator will be made adaptable to be used by other researchers for other EQ-5D-5L value sets.Methods: This project will make use of the published value set using the prefered model in the Egyptian EQ-5D-5L valuation study. The calculator will be developed using Microsoft Excel , ensuring accessibility across various devices and platforms. Validation will be performed to ensure accuracy and ease of use. A detailed procedure will be developed and made available online for other researchers to be able to easily adapt the caclulator to other value sets as they emerge.
